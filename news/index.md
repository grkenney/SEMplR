# Changelog

## SEMPLR 1.1.2

- Adjusted
  [`enrichSEMs()`](https://grkenney.github.io/SEMPLR/reference/enrichSEMs.md)
  function to only consider the highest scoring binding orientation for
  each sequence/SEM combination in enrichment calculations
- Documentation updates to
  [`scoreVariants()`](https://grkenney.github.io/SEMPLR/reference/scoreVariants.md),
  [`enrichSEMs()`](https://grkenney.github.io/SEMPLR/reference/enrichSEMs.md),
  and the vignette.

## SEMPLR 1.1.1

- Fixed bug in
  [`plotSEMMotifs()`](https://grkenney.github.io/SEMPLR/reference/plotSEMMotifs.md)
  that was mislabeling plotted motifs with scores for both reverse and
  forward orientations
